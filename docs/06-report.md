# 报告可视化

版本 0.1 ｜ 对应 `packages/report`，命令 `pnpm cli report <editionId>`

报告是一份自包含的 HTML，内联 SVG 与脚本，无外部依赖，可直接用浏览器打开或归档。它回答一个问题：结构遍在这本书上跑得怎么样。设计遵循 dataviz 技能的流程：先定形式，再按职责配色，用脚本验证调色板，再套用标记规格、悬停层和无障碍要求。

## 1. 形式

| 数据的任务 | 形式 | 颜色职责 |
|---|---|---|
| 四个头条数字：已解析章节、对白分段、消解比例、未知说话人 | KPI 行，消解比例配同色系量表 | 无 |
| 每章对白按归属状态分层 | 堆叠柱状图 | 状态色，配图标与图例 |
| 每章旁白与对白字数占比 | 100% 堆叠柱状图 | 分类色，两个序列 |
| 角色对白数量排序 | 水平条形图，单序列 | 单一色相，无图例 |
| 角色在各章的提及次数 | 热力图 | 顺序色，单色相由浅到深 |

超过 30 章时，按章的图把章节折成等宽的连续区间，柱子保持可点击的宽度。角色条形图最多显示 10 人，其余折成"其他"并用去强调灰；热力图最多 12 人。

## 2. 颜色

全部取自 dataviz 参考调色板，浅色与深色是同一组色相各自选定的步进，不是自动翻转。热力图的深色模式反向使用蓝色渐变，让"多"在深色底上更亮。

| 角色 | 浅色 | 深色 |
|---|---|---|
| series-1 蓝 | `#2a78d6` | `#3987e5` |
| series-2 橙 | `#eb6834` | `#d95926` |
| status-good | `#0ca30c` | `#0ca30c` |
| status-warning | `#fab219` | `#fab219` |
| status-serious | `#ec835a` | `#ec835a` |
| 热力 1 到 7 | 蓝 100 到 700 | 蓝 700 到 100 |

归属状态图用状态色而不是分类色，因为"已消解 / 仅称呼 / 未知"是好坏有别的状态。状态色在浅色底上 warning 与 serious 低于 3:1 对比，按规范以图例图标（✓ ~ ?）和表格视图作为补偿，颜色从不单独承载含义。

## 3. 验证记录

验证命令（在 dataviz 技能目录下）：

```bash
node scripts/validate_palette.js "#2a78d6,#eb6834" --mode light
node scripts/validate_palette.js "#3987e5,#d95926" --mode dark --surface "#1a1a19"
node scripts/validate_palette.js "#cde2fb,#9ec5f4,#6da7ec,#3987e5,#256abf,#184f95,#0d366b" --ordinal --mode light
node scripts/validate_palette.js "#0d366b,#184f95,#256abf,#3987e5,#6da7ec,#9ec5f4,#cde2fb" --ordinal --mode dark --surface "#1a1a19"
```

结果见本文件末尾的"验证输出"。分类色两个序列在两种模式下均通过；热力图渐变按顺序检查通过。状态色不是分类调色板，不用分类检查，只记录其对比度表（见参考调色板文档）。

## 4. 标记与交互

- 柱子最宽 24px，顶端 4px 圆角，底部方角；堆叠段之间 2px 底色间隙。
- 网格与基线是 1px 实线，一步偏离底色。
- 条形图值标在条尾；堆叠图只在最后一根柱旁直接标注序列名，且相互碰撞时整体放弃，交给图例与悬停。
- 每根柱、每根条、每个热力格都是悬停与键盘焦点目标，命中区大于标记本身，最小 24px；悬停面板值在前、序列名在后，用短线键标识序列。
- 每张图有表格视图开关，表格与悬停显示同一组值。
- 主题选择：跟随系统 / 浅色 / 深色，存于 localStorage。
- 纹理开关：开启后分类与状态标记换成 45° 与 135° 的线条填充；打印和 forced-colors 模式自动开启。热力图保持明度渐变，不加纹理。
- 页面内所有来自数据库的字符串都经过转义；悬停面板用 textContent 重建，不拼接 HTML。

## 5. 反模式自检

- 没有双轴图；旁白与对白字数用 100% 堆叠而不是两条 y 轴。
- 没有按数值给名义类别染色；角色条形图所有条同一色相。
- 没有超过 8 个分类色；角色超出上限折成"其他"。
- 没有在每个数据点上标数字。
- 没有饼图。
