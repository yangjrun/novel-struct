# novels/

放待导入的小说原文。此目录除本文件外全部被 git 忽略。

支持 TXT 和 EPUB，按文件内容而不是扩展名区分（ZIP 容器即 EPUB）。

TXT：

- UTF-8 或 GBK / GB18030 编码均可，有无 BOM 均可。
- 章节标题独立成行：`第X章`、`第X回`、`第X节`，可带标题；卷标题 `第X卷`；`楔子`、`序章`、`番外`、`后记` 也识别。
- 第一个标题之前的文字会成为"前言"章；卷标题与首章之间的文字会成为该卷的"卷首语"章。
- 正文缩进（全角空格或制表符）而作者留言不缩进的文件里，不缩进且含“请假”“感言”“更新”“盟主”等字样的行会切成“作者的话”（`note`）章，不并入正文。
- 正文中重复出现的换页标题（下载站常见的 `第554章血的味道` 夹在第 554 章中间）按正文保留，导入时给出警告。

EPUB：

- 按阅读顺序（spine）读取正文，每个块级元素一行；目录（EPUB 3 的 nav 或 EPUB 2 的 NCX）的每个条目就是一个章节或卷的起点，条目标签再走一遍上面的标题规则，所以 `第X卷`、`番外`、`请假一天` 等照样识别。
- 目录里“封面”“版权信息”“简介”“目录”这类条目归入 `front_matter`；有子条目的分组（`第一卷 xxx` 或 `正文`）成为卷。
- 没有目录的 EPUB 退回到 h1 到 h3 标题加章节标题规则。
- 书名和作者取自 EPUB 元数据，导入时可以不填 `--title`。
- 只有图片没有文字的页面（封面）会被跳过并给出警告。

导入：

```bash
pnpm cli import novels/某书.txt --title "书名" --author "作者"
pnpm cli import novels/某书.epub            # 书名作者取自元数据，也可以用 --title 覆盖
```

同一书名同作者同标签再次导入会原地更新，章节 ID 与未变章节的解析结果保留。导入后正文存于数据库（默认 `data/novelstruct.pglite`），原文件不再被读取。示例文件见 `packages/ingest/test/fixtures/demo-novel.txt`。
