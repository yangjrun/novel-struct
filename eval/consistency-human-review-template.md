# 一致性遍人工金标记录模板

本文件是**待人工填写的模板**，不是金标，不计准确率。逐条比对固定版本的规范化原文和候选；Jev 意见只供参考，不能代替标注。

## 固定评测条件

| 项目 | 填写 |
|---|---|
| 书 / 版本 ID / 原文章节编号 | 待填写 |
| 结构遍版本与模型 | 待填写 |
| 一致性遍提示词版本、模型、Context Builder 预算 | 待填写 |
| 预览 JSON 路径与 `sourceHash` / `previewHash` | 待填写 |
| 标注者、复核者和日期 | 待填写 |

## 逐条候选标注（每条一行，可复制下表）

| candidate key / hash | 引用精确定位 | 完整断言是否仅由该引用支持 | 人物/属性归属 | `storyTime` 与锚点 | 状态字段可复用性 / 事件是否重复 | 人工结论与理由 |
|---|---|---|---|---|---|---|
| 待填写 | 是 / 否 | 支持 / 矛盾 / 证据不足 / 不确定 | 正确 / 错误 / 不适用 | 正确 / 错误 / 不适用 | 正确 / 错误 / 不适用 | 保留 / 修订 / 删除 / 无法判断；注明原文位置 |

另为**该抽取而遗漏的应有事实**记录原文位置、类型、预期断言和证据，避免模型输出空数组时获得虚高分数。每章分别核对状态跨章变更（旧值和生效范围）、伏笔提出与解决是否具有本章独立引用、实体别名消解与合并拆分；纯 ID 的 `resolveForeshadowIds` 在补证据协议前均列为未评测。

## 汇总规则

- 先报请求章节数、作答章节数、模型拒绝／限流章节数、已评测候选数与人工实际标注数；仅对完成人工标注的候选计算支持率或错误率。
- 引用的 UTF-16 切片吻合仅算定位通过，不能算断言被支持；机器 `supports` 不能算人工批准。
- 不同模型、提示词、上下文或金标版本单独成组；不将失败章节从请求覆盖分母中隐藏，也不把未评测归因于解析准确率。
- 区分“候选事实正确性”和“关键事实召回”；保留至少一组应抽取与不应抽取的否定样本。助手整理的 `consistency-quality-cases.md` 中 12 点必须由独立人类核对后才可升级为人工金标。
